# Bonzur

**Bonzur** is an augmented reality application built with Unity and Vuforia Engine, designed to deliver an interactive AR experience through real-time image recognition and 3D visualization.

The project features a custom 3D flower model created in **Blender** and demonstrates marker-based AR object tracking on mobile devices.

## Tech stack
- **Engine:** Unity  
- **AR SDK:** Vuforia  
- **3D Modeling:** Blender  
- **Language:** C#

## Features
- Image recognition to detect specific targets  
- Real-time tracking of objects in AR  
- Interactive 3D flower visualization
- Custom 3D assets designed in Blender
- Engaging AR user experience  

## Assets
- Custom 3D flower model and petals created in Blender
- Additional textures and supporting assets sourced from:
- Sketchfab
- Unity Asset Store

All third-party assets are used in accordance with their respective licenses.

## Prerequisites
- Unity Hub
- Compatible Unity Editor version
- Vuforia Engine package installed
- A Vuforia License Key (configure in Unity under Vuforia Configuration)
- Supported mobile device for AR deployment

## Configuration

Before running the project, configure your Vuforia license key:

1. Open the project in Unity
2. Navigate to:
Edit > Project Settings > Vuforia Engine
3. Paste your App License Key
