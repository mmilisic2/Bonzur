# Bonzur

**Bonzur** is an augmented reality (AR) application built in Unity using the Vuforia engine, featuring a 3D flower modeled in Blender. The app demonstrates interactive AR visualization with real-time image recognition and object tracking.

## Technologies
- **Engine:** Unity  
- **AR SDK:** Vuforia  
- **3D Modeling:** Blender  
- **Scripting:** C# for interactive AR features  

## Assets
- 3D flower model and petals designed by the developer in Blender  
- Additional models and textures sourced from Sketchfab and Unity Asset Store, used according to their licenses  

## Features
- Image recognition to detect specific targets  
- Real-time tracking of objects in AR  
- Interactive 3D flower visualization  
- Engaging AR user experience  

## Prerequisites
- Unity  
- Vuforia Engine package  
- A Vuforia License Key (configure in Unity under Vuforia Configuration)  

## Getting Started
1. Clone the repository:  
   ```bash
   git clone https://github.com/mmilisic2/Bonzur.git
2. Open the project in Unity.
3. Configure your own Vuforia license key in the Unity Editor via Edit > Project Settings > Vuforia > App License Key.
4. Build and run the AR application on a supported device.
